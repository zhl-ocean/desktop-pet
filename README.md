# 布偶猫桌宠

Windows 透明置顶桌面宠物（Electron）。

## 直接使用

双击以下任一文件即可运行：

- `dist/布偶猫桌宠.exe`
- 桌面上的 `布偶猫桌宠.exe`

## 功能

- 自由拖拽：按住宠物可拖到桌面任意位置，靠边会吸附
- 点击互动：单击触发小动作与趣味中文气泡
- 自主走动：随机游走、停顿、发呆（右键可开关）
- 窗口置顶：始终悬浮陪伴（右键可开关）

## 操作说明

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 移动桌宠 |
| 左键单击 | 互动动作 + 气泡 |
| 滚轮 | 放大缩小 |
| 右键菜单 | 调整大小、自主走动、置顶、退出 |

## 开发

```bash
npm install
npm run remove-bg
npm start
npm run build
```
